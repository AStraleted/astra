FAQ

Коротко о будущем продукте.

Это уже подключено к SMSCodex?

Да. Кабинет работает через Cloudflare Worker: справочники, наличие, баланс, покупка номера, проверка SMS-кода, отмена и завершение заказа.

Где хранится API-ключ SMSCodex?

Только в Secrets Cloudflare Worker. В index.html ключа нет, поэтому GitHub Pages не раскрывает его посетителям.

Почему нужен Cloudflare Worker?

GitHub Pages не выполняет серверный код. Worker выступает маленьким backend-прокси: держит секреты, проверяет вход и делает разрешённые запросы к SMSCodex.
